| 配置、日志、历史提交及压缩包 | 扫描当前文本、可读取 ZIP/wheel/DOCX/PDF 内容及 Git 可达对象；测试用假密钥保留并明确识别，不能误删安全测试 |

## 复现与观测边界

Python 3.9+；安装源码或 wheel 后可使用 `kmb`。离线入口为 `python3 -m kmb.cli official-acceptance --out runs/official-acceptance`。网页启动与真实 Agent 前置条件见仓库 quick-start 文档。

本次六案例衡量短场景系统行为；未观测的模型内部记忆和跨多天稳定性不作结论。OpenClaw 日期笔记采集遗漏和禁旧值字符串规则限制在当前介绍中说明。发布和文件检查不等同于官方评审通过或正式邮件提交成功。
