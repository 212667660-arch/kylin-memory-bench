## 实际修改与核对

小K 本机配置命令只支持对已经存在的动态 provider 字段应用修改。先加入不含新明文密钥的 provider 元数据，再通过原生加密 setter 写入密钥并切换 fallback；原生配置加载与 TOML 解析已确认新模型和 URL。

OpenClaw 同步更新 `openclaw.json`、Agent 的 `models.json` 和私有环境文件，移除默认模型中旧网关的绑定并禁止回退到旧网关。当前安装的 OpenClaw 2026.9.5 已通过原生配置结构校验；新网页服务继承实际演示 HOME 和密钥环境引用。

独立核对时，清除检查进程临时注入的 DEEPSEEK_API_KEY，OpenClaw 仍可从私有环境文件加载配置；原生 config get 确认默认模型与 Base URL。小K reliability fallback_providers 和 model_routes 均为空，不会因旧路由配置重新选择网关。

初次修改被本地配置注册表拒绝后已自动回滚，随后按动态字段格式完成。最终状态为 configured，工作台 PID 8843；小K和 OpenClaw 命令/存储就绪，Hermes 的隔离目录仍未准备，KylinAgent 仍需手动观测。日常配置/记忆、演示记忆与操作系统版本文件的前后快照一致。

记录在 `runs/deepseek-api-switch-20261014/configuration-status.json`。仅核对配置结构、实际配置加载和本地工作台元数据；没有发出模型请求、联网验证密钥、查询余额或运行测试套件。因此 configured 不等于新密钥已通过云端认证，也不等于新 API 有充足余额。

## 配置依据

[DeepSeek 官方接入说明](https://api-docs.deepseek.com/)推荐 canonical 模型名 `deepseek-flash`；旧 `deepseek-v4-flash` 名称仍接受，但官方现转到对应的 Flash 服务版本。

[DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)说明默认启用思考，可通过请求体 `thinking.type=disabled` 关闭。本次双方统一关闭，以保持一致并避开旧客户端思考工具历史字段兼容问题。

[OpenClaw 模型配置说明](https://docs.openclaw.ai/gateway/config-agents/models)记录 `params.extra_body` 的请求体覆盖方式；已同时对照本机 2026.9.5 的 schema 和请求参数实现，不仅依赖线上文档。
