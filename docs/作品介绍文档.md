## 项目背景与目标

智能体需要在后续对话和任务中使用正确记忆，同时抑制敏感、临时或已经过期的信息。人工问答难以覆盖冲突更新、相近实体、错误持久化和任务复用，也难以解释得分如何产生。

KylinMemoryBench 执行声明式 YAML 案例，采集可观察的对话、记忆和动作事件，用确定性规则评分，输出六维结果、雷达图、失败原因和证据回溯。评测对象是智能体及其记忆/动作机制的系统级行为；未观察到模型内部记忆时，不声称模型具有原生长期记忆。

## 六类能力与数据设计

| 能力 | 验证目标 |
| --- | --- |
| 长期保持 | 后续交互能否使用应保留的信息 |
| 记忆调用 | 是否调用正确的记忆键、值或可观察记录 |
| 动态更新 | 新条件能否覆盖旧值并用于回答和任务 |
| 相近区分 | 相似实体和字段是否被混淆 |
| 边界识别 | 不应保留的信息是否被抑制持久化 |
| 任务复用 | 后续任务是否按记忆产生正确动作和工件 |

quick.yaml 含六例，每类能力一例；中文核心六例、中文扩展十八例、英文核心六例，生命周期创新套件十五例，另有对抗与原生决策套件。覆盖清单登记四十九项；清单与执行套件存在引用和复用，不能把 YAML 行数相加当作独立样本数，也不宣称所有案例已在所有真实智能体上实跑。

快速对比默认 Seed 42、失败重试一次、单案例超时 180 秒。记录套件、参数与评分器版本便于复现；六例属于短场景抽样，不替代跨多天的保持能力实验。

## 技术架构与使用流程

主机发现与预检 → 智能体适配器 → 案例执行 → EvidenceEvent → 规则评分 → 结果、雷达与证据回溯。

适配层支持原生命令、HTTP、记忆层及离线/回放方案。证据层记录来源、类型、案例和步骤；评分层输出结构化结果与解释。执行错误、网关失败、额度不足和行为扣分分开呈现，不把调用失败当作有效能力分数。

网页支持智能体发现、双智能体选择、任务进度、运行历史、六维雷达、案例与双方证据下钻。用户选择两款已就绪智能体，启动评测，等待完成后打开同一批次结果与证据；高级入口保留记忆层与离线对照。CLI、Python wheel 和 Debian 包提供部署入口。

## 原生 API 配置识别与隐私

0.2.5 包含原生 API 状态检测：读取默认服务商、模型、配置来源及凭据存在状态，区分后端宿主机与独立评测 HOME。Windows 后端不会读取 VM 内的安装；浏览器所在机器也不改变检测对象。

工作台 API 档案保存公共接口、模型与凭据变量名，不覆盖原生智能体的自身配置。页面不返回密钥，不解密原生凭据，不执行外部取密命令，也不因刷新状态调用模型。凭据存在、命令/存储就绪、鉴权成功和账户有额度是不同结论。

2026-10-15 在原 openKylin 3.0 上已识别小K KylinBot、OpenClaw、Hermes 的安装、命令/记忆存储和自身 API 配置；KylinAgent 已安装且发现配置，仍需手动观测。Windows/VM 的真实页面、API 档案查看与取消编辑、检测修订版 2 已核对，未新增模型调用。

## 验证与真实历史样例

本机完整离线回归运行 203 项，202 项通过，一项因 Windows 符号链接权限跳过；Windows/Python 3.9、Ubuntu/Python 3.12 与 Debian 生命周期的 GitHub 检查已有通过记录。本轮 0.2.5 的构建来源、具体验证结果见随附 manifest、verification-summary 和发布页，未验证项不以历史测试替代。

历史批次 quick-20261014-124015-11577059 中，小K与 OpenClaw 各六例，双方 score_valid=true、error_cases=0，总分 22.22 / 36.11；本轮只读复核原结果确认这些值。它属于 0.2.4 演练，不是 0.2.5 新复跑；低分、失败原因和网关失败历史保留。

已知边界：OpenClaw 日期笔记采集未覆盖全部文件；禁旧值检查为字符串规则；部分历史时间元数据缺失；小K自定义接口独立字段和原生详情间距仍可改善。缺少可观察事件不等同于没有记忆能力；工程自评不代表组委会评分。

## 视频与批次限制

原始剪辑成片约四分五十秒，H.264/AAC、1728×1080，展示 openKylin 桌面、双智能体选择、评测启动、雷达、案例、证据和运行历史。原片不编辑，SHA-256 与原发布一致。

视频启动 quick-20261014-193216-73367531，结果及证据展示 12:40 的有效历史批次；部分“本次/刚刚”口播存在批次对应限制。它可展示功能与历史样例，不能证明 19:32 新任务连续完成并产生上述分数，也未完整展示后来新增的原生 API 分区。该限制随视频一并提交，不改写真实数据。

## 应用、创新与维护

面向 openKylin 社区生态评测、开发者记忆功能回归、企业失败定位和教学研究。统一证据来源、可解释规则、主机安装发现和网页证据回溯，使配置条件、执行错误和行为得分能够分别检查。参考/缺陷基线验证规则区分度，B 轨支持受控记忆机制比较。

项目提供 MIT 许可、第三方声明、贡献指南与测试。后续扩大跨会话、多实体、噪声和跨日实验，改善观测覆盖、历史元数据及评分解释，持续公开有效率与失败样例。提交包含可复现离线样例；真实评测仍需安装智能体并配置有效模型服务。
