# KylinMemoryBench 作品介绍

2026 上海开源软件应用创新大赛 · 开源 AI 工具赛道 · openKylin 企业命题

材料日期：2026-10-14。当前源码版本：0.2.4。实际演示环境：原 openKylin 3.0。

## 项目背景与目标

智能体需要在后续对话和任务中正确使用记忆，同时避免保留敏感或临时信息。人工问答难以覆盖冲突更新、相近实体、错误持久化和任务复用，也难以解释一次得分如何产生。

KylinMemoryBench 提供统一的自动化评测流程：执行声明式案例，采集可观察的对话、记忆和动作事件，按确定性规则评分，并输出六维结果、雷达图和可追溯证据。适用对象是智能体及其外部记忆和动作机制的系统级行为；没有观察到模型内部记忆时，不作模型原生长期记忆结论。

## 六类能力与数据设计

| 能力 | 关注的问题 |
|---|---|
| 长期保持 | 后续交互能否使用应保留的信息 |
| 记忆调用 | 能否调用对应的键、值或可观察记忆 |
| 动态更新 | 新值是否覆盖旧值，回答是否符合更新后的条件 |
| 相近区分 | 相似实体和字段是否被正确区分 |
| 边界识别 | 敏感或临时信息是否被抑制持久化 |
| 任务复用 | 后续任务是否依据记忆产生正确动作和工件 |

案例以 YAML 定义用户轮次、记忆条件、动作及评分检查。已有中文、英文、对抗和生命周期套件，覆盖清单列示 49 个案例；各套件存在复用，不能将文件内案例数简单相加。网页快速对比固定使用 quick.yaml 的六个案例，每个能力一个案例，默认 Seed 42、失败重试 1 次、单案例超时 180 秒。六案例属于短场景抽样，不替代跨多天的保持能力实验。

## 技术架构与网页使用流程

流程为：智能体发现与预检 → 统一适配器 → 案例执行 → EvidenceEvent → 规则评分 → 结果、雷达和证据回溯。

网页后端检查其所在主机上的可执行文件、配置文件和记忆存储。浏览器访问另一台机器时，检测对象仍是运行后端的主机。已安装、当前目录就绪、凭据存在和真实调用成功是不同状态，均按实际结果呈现。

用户在总览勾选两款已就绪的智能体，点击“开始快速对比”，等待任务结束，再查看结果中心的六维分数、雷达、案例评分原因和双方证据。运行历史可以重新打开已保存的同一批次。高级入口可选择 A 轨生态智能体、B 轨记忆层或离线/回放对照，轨道只负责归类和过滤，不改变证据的来源语义。

真实 Agent 沿用各自的运行入口和模型配置。API/模型页面中的 HTTP 档案与原生 Agent 的私有配置分开管理；“未配置 HTTP 凭据”不能直接解释为原生 Agent 无法调用模型。原生凭据通过本机配置安全加载，不放入代码、提交包或网页展示。

## 真实验证与结果解释

2026-10-14 的有效演练批次为 quick-20261014-124015-11577059。小K KylinBot 与 OpenClaw 各完成六个案例，双方 score_valid=true、error_cases=0；总分分别为 22.22 和 36.11，动态更新分别为 33.33 和 66.67。这些是本批规则评分，保留低分和失败原因，不作为智能体所有记忆能力的最终排名。

该批次在原 openKylin 3.0 中使用独立演示记忆副本运行，当前软件版本为 0.2.4。新 DeepSeek 配置在该批调用成功，余额未查询；本轮提交整理未再次调用模型或运行测试套件。历史 0.2.2 的 176 项测试与发行验证另有归档，不表述为 0.2.4 全量回归结果。

已知解释限制：OpenClaw 日期笔记的采集范围未覆盖全部文件；缺少记忆事件不等同于没有记忆能力。回答禁旧值检查是字符串规则，回答正确选择新值但解释旧值也可能扣分，需结合原始文本判断。部分历史记录的时间与耗时元数据缺失。这些问题如实保留，没有修改分数或追补历史事件。

## 应用场景、创新与维护

面向 openKylin 社区的生态评测、智能体开发者的失败定位、企业记忆功能回归和教学研究。统一事件模型保留来源与观测边界，确定性规则给出失败原因，网页把发现、运行和证据回溯连接起来；B 轨支持在受控条件下比较记忆机制。

项目采用 MIT 许可，保留第三方声明与贡献指南。源码、配置示例、套件和脚本可获取；真实 API Key、密码、私钥和私有 Agent 配置不随材料分发。后续计划扩大跨会话、多实体、噪声和跨日批次，优先改进观测覆盖、历史元数据和评分解释，并公开有效率与失败样例。

代码仓库：https://github.com/212667660-arch/kylin-memory-bench

离线复现：安装 Python 3.9+ 与项目依赖后，执行 `python3 -m kmb.cli official-acceptance --out runs/official-acceptance`。真实生态评测需另外准备本机 Agent、记忆存储及有效模型凭据。源码 0.2.4 与历史 0.2.2 安装包不得混用版本声明；本次交付明确列出安装包版本、哈希及验证范围。
