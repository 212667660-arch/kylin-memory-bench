# F4: Agent frameworks on openKylin/Linux

## Findings

### [1] LangChain (official repo) is MIT-licensed, installable via `uv add langchain` / `pip install langchain`, Python >=3.10,<4.0, supports OpenAI and extras including `mcp` and `ollama`; pure Python → Linux-runnable, no openKylin official adaptation claimed.
- quote: "uv add langchain" / "Requires Python <4.0.0, >=3.10.0" / "Provides Extra ... mcp ... ollama ... openai"
- url: https://github.com/langchain-ai/langchain and https://pypi.org/project/langchain/
- source_type: primary
- published: PyPI verified Sep 16, 2026 (langchain 1.4.1)
- confidence: high

### [2] LangGraph (official) is MIT, `pip install -U langgraph` / `uv add langgraph`, Python >=3.10; README documents short-term + long-term persistent memory and multi-agent orchestration — strongest fit for a long-term memory Benchmark among the six.
- quote: "Comprehensive memory — Create truly stateful agents with both short-term working memory for ongoing reasoning and long-term persistent memory across sessions." / "pip install -U langgraph"
- url: https://github.com/langchain-ai/langgraph and https://pypi.org/project/langgraph/
- source_type: primary
- published: langgraph 1.2.11 PyPI Aug 11, 2026
- confidence: high

### [3] LangGraph official Memory docs define short-term (thread/checkpointer) vs long-term (store, cross-session namespaces) and semantic/episodic/procedural memory types — suitable baseline for long-term memory Benchmark design on Linux/openKylin.
- quote: "Long-term memory stores user-specific or application-level data across sessions and is shared across conversational threads... LangGraph provides stores to let you save and recall long-term memories."
- url: https://docs.langchain.com/oss/python/langgraph/memory
- source_type: primary
- published: unknown (live docs, fetched 2026-09-18)
- confidence: high

### [4] AgentScope 2.0 (agentscope-ai/agentscope; formerly modelscope) is Apache-2.0, requires Python 3.11+, install `uv pip install agentscope` / `pip install agentscope` (PyPI 2.0.8, Sep 8 2026); OS Independent; multi-agent Agent Team; MCP Toolkit + GitHub MCP Registry hub; Memory backends Agentic/ReMe/Mem0; models include OpenAI and Ollama — Linux-runnable, not openKylin-adapted.
- quote: "AgentScope requires Python 3.11 or higher." / "uv pip install agentscope" / "AgentScope is released under Apache License 2.0." / "Memory: Agentic memory with switchable backends (ReMe, Mem0)"
- url: https://github.com/agentscope-ai/agentscope and https://pypi.org/project/agentscope/
- source_type: primary
- published: GitHub news through 2026-09; PyPI 2.0.8 Sep 8, 2026
- confidence: high

### [5] AgentScope long-term memory docs document three middleware backends (AgenticMemoryMiddleware markdown-file, ReMeMiddleware, Mem0Middleware) with cross-session recall — highly suitable for long-term memory Benchmark on openKylin/Linux.
- quote: "Long-term memory is an agent's ability to retain information across sessions... AgentScope currently supports the following long-term memory implementations: Agentic Memory, ReMe, Mem0"
- url: https://docs.agentscope.io/latest/en/building-blocks/long-term-memory
- source_type: primary
- published: unknown (live docs, fetched 2026-09-18)
- confidence: high

### [6] Qwen-Agent (QwenLM) is Apache-2.0; install `pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"`; GUI requires Python 3.10+; supports MCP, RAG for 1M-token docs, DashScope or OpenAI-compatible local vLLM/Ollama; README claims memory/planning capabilities — Linux-runnable (Docker for code interpreter), not openKylin-adapted.
- quote: "pip install -U \"qwen-agent[gui,rag,code_interpreter,mcp]\"" / "[mcp] for MCP support." / "based on the instruction following, tool usage, planning, and memory capabilities of Qwen"
- url: https://github.com/QwenLM/Qwen-Agent and https://pypi.org/project/qwen-agent/
- source_type: primary
- published: qwen-agent 0.0.34 PyPI Feb 16, 2026
- confidence: high

### [7] Qwen-Agent MCP FAQ shows config for `@modelcontextprotocol/server-memory` and filesystem/sqlite servers, plus OpenAI-compatible `model_server` for local models — MCP and local models documented; long-term memory is thinner than LangGraph/AgentScope/CrewAI (RAG-oriented).
- quote: "\"memory\": { \"command\": \"npx\", \"args\": [\"-y\", \"@modelcontextprotocol/server-memory\"] }" / "Use a model service compatible with the OpenAI API, such as vLLM or Ollama"
- url: https://github.com/QwenLM/Qwen-Agent
- source_type: primary
- published: Feb 2026 README
- confidence: high

### [8] Microsoft AutoGen is in maintenance mode (successor: Microsoft Agent Framework); MIT code + CC-BY-4.0 docs; Python 3.10+; install `pip install -U "autogen-agentchat" "autogen-ext[openai]"`; OpenAI API quickstart; MCP via McpWorkbench; multi-agent AgentTool orchestration — Linux-runnable but weak for new long-term-memory benchmarks.
- quote: "AutoGen is now in maintenance mode. It will not receive new features... New users should start with Microsoft Agent Framework." / "AutoGen requires Python 3.10 or later." / "pip install -U \"autogen-agentchat\" \"autogen-ext[openai]\""
- url: https://github.com/microsoft/autogen
- source_type: primary
- published: fetched 2026-09-18 (GitHub footer © 2026)
- confidence: high

### [9] CrewAI is MIT; Python >=3.10 and <3.14; official Linux install via uv (`curl -LsSf https://astral.sh/uv/install.sh | sh` then `uv tool install crewai`); default OpenAI API; local models via Ollama/LM Studio; Key Features list memory, knowledge, MCP/A2A, multi-agent Crews/Flows — explicit Linux support, not openKylin-official.
- quote: "CrewAI requires Python >=3.10 and <3.14." / "macOS/Linux: curl -LsSf https://astral.sh/uv/install.sh | sh" / "uv tool install crewai" / "You can configure your agents to use a local model via the Ollama tool." / "CrewAI is released under the MIT License."
- url: https://github.com/crewAIInc/crewAI
- source_type: primary
- published: fetched 2026-09-18
- confidence: high

### [10] CrewAI official Memory docs describe a unified long-term Memory API (remember/recall, hierarchical scopes, composite semantic+recency+importance scoring, LanceDB storage, Ollama local LLM/embedder) — strongly suitable for long-term memory Benchmark on Linux/openKylin.
- quote: "CrewAI provides a unified memory system -- a single Memory class that replaces separate short-term, long-term, entity, and external memory types with one intelligent API."
- url: https://docs.crewai.com/en/concepts/memory
- source_type: primary
- published: unknown (live docs, fetched 2026-09-18)
- confidence: high

### [11] openKylin official site (OpenAtom, MulanPSL2) and a 2026-09-16 news teaser "openKylin 3.0玩转智能体" do NOT claim official adaptation of LangChain/LangGraph/AgentScope/Qwen-Agent/AutoGen/CrewAI; none of the six framework READMEs mention openKylin — treat all six as Linux-runnable only, not openKylin official adaptation.
- quote: "直播预告 | openKylin 3.0玩转智能体！直播间现场见" (news title only; no framework adaptation named) / "OpenAtom openKylin ... 由开放原子开源基金会孵化及运营"
- url: https://www.openkylin.top/ and https://www.openkylin.top/news/4140-cn.html
- source_type: primary
- published: 2026-09-16
- confidence: medium (negative evidence: official pages fetched do not list these frameworks; deeper openKylin Gitee/package repos not exhaustively searched)

### [12] Cross-framework summary matrix for openKylin/Linux use (all six are pure-Python packages installable on any Linux with pip/uv; none openKylin-official): LangGraph ≈ AgentScope 2.0 ≈ CrewAI best for long-term-memory Benchmark; LangChain depends on LangGraph for persistence; Qwen-Agent good for MCP+local Qwen+RAG; AutoGen maintenance-mode — prefer Microsoft Agent Framework for new projects.
- quote: "Agent-ready capabilities: Use tools, memory, knowledge, checkpointing, async execution, and MCP/A2A support for more capable production agents." (CrewAI) + AutoGen maintenance notice + LangGraph/AgentScope memory quotes above
- url: https://github.com/crewAIInc/crewAI / https://github.com/microsoft/autogen / https://github.com/langchain-ai/langgraph / https://github.com/agentscope-ai/agentscope
- source_type: primary
- published: 2026-09-18 synthesis
- confidence: medium
